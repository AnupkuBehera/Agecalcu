Open Source Client-Side SDK

Dobcal Developer API

Zero dependencies, zero network requests, 100% client-side precision calendar calculation.

1. Installation & Import

Import the standalone calculation engine into your web application via script tag or ES module:

<script src="https://dobcal.pages.dev/js/calculator.js"></script>

2. Core Methods Reference

METHOD AgeCalculator.calcAge(dob, asOf)

Calculates chronological years, months, and days using month-end borrowing with leap-year handling. 

const result = AgeCalculator.calcAge('2000-01-01', '2026-01-01');
console.log(result.years, result.months, result.days); // 26, 0, 0
console.log(result.totals.days); // 9497
console.log(result.westernZodiac.name); // Capricorn
METHOD AgeCalculator.calcRetirementAndPension(dob, doj, retAge)

Computes exact retirement date, remaining service, and qualifying pension years.

METHOD AgeCalculator.calcPlanetaryAges(dob)

Computes chronological age on Mercury, Venus, Mars, Jupiter, Saturn, Uranus, and Neptune.

METHOD AgeCalculator.generateIcsCalendar(options)

Generates valid RFC 5545 iCalendar (`.ics`) file strings with annual recurrence.

Frequently Asked Questions

      

        

          
            Is the Dobcal calculation SDK free to use?
            ↓
          
          

            Yes, the Dobcal calculation engine is completely free and open-source under the MIT license. You can embed it directly into your own frontend websites or backend Node.js applications.
          

        


        

          
            Are API calls rate-limited or require an API key?
            ↓
          
          

            Because the SDK runs 100% client-side inside your user's browser, there are zero network calls, zero rate limits, and no API keys required.
          

        


        

          
            How do I embed the calculator widget into my WordPress or HTML site?
            ↓
          
          

            You can embed our lightweight iframe widget by adding <iframe src='https://dobcal.pages.dev/embed-widget.html' width='100%' height='380' frameborder='0'></iframe> to your site.
